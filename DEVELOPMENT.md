## Local preview (Windows)

1. Install the official Quarto CLI: https://quarto.org/docs/get-started/
2. Clone the repository and switch to branch `dev`.
3. Run `quarto preview` from the repository folder.
4. Review navigation, themes, languages and interactive example.
5. Run `quarto render` to generate the static site under `_site/`.
